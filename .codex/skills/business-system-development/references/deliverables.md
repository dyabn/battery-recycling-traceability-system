# 交付物规划

课程交付物应随阶段逐步产生，不得在项目开始时一次性生成空洞文档。以下 27 项是交付物目录，不代表当前阶段全部创建。

## 业务分析类

1. 业务资料索引
2. 业务定位说明
3. C1 业务定位确认记录
4. 全局业务基线
5. 业务结构分解说明
6. 业务结构图源文件
7. 业务角色与职责说明
8. 业务对象说明
9. 业务规则清单
10. 异常场景清单
11. C2 全局业务基线确认记录

## 切片分析类

12. 业务切片选择评分表
13. 切片流程说明
14. BPMN / UML 活动图源文件
15. 状态机说明
16. 人机边界表
17. 信息流和数据流说明
18. C3 业务切片确认记录

## 需求与原型类

19. 系统需求规格说明
20. 用例说明
21. 权限需求说明
22. 验收标准
23. 测试用例说明
24. UI 原型说明
25. API / Mock 契约
26. C4 原型确认记录

## 工程交付类

27. 系统设计、代码、测试报告和交付说明

## 生成规则

- 当前阶段只生成当前阶段需要的交付物。
- 交付物必须有版本号、来源、状态和待确认问题。
- 已确认交付物形成基线，后续变更必须记录影响范围。
- 图形交付物应保存可编辑源文件，图片只作为导出结果。
- 测试用例必须追溯到需求，需求必须追溯到业务规则或业务节点。
