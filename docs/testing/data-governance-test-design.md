# 数据治理测试设计 V0.1

文档状态：待评审
关联变更：CR-DG-001
目标基线：V1.1

## 1. 测试范围

纳入：

- 固定质量规则查看。
- 手工质量检查。
- 检查结果和质量问题生成。
- 问题分配、处理、复核和关闭。
- 数据质量看板。
- 权限、审计和企业隔离。

排除：

- 自定义脚本规则引擎。
- 大数据平台和数据湖。
- AI 自动修复。
- 真实监管平台对接。
