系统名称：面向动力电池回收利用企业的流转协同与追溯管理系统  
切片名称：回收接收 -> 电池登记 -> 验收 -> 入库 -> 库存可见  
当前阶段：prototype-and-requirements  
当前关口：C4  
文档状态：待评审

边界说明：本文只定义测试设计和追踪关系，不编写自动化测试代码，不设计数据库、API 或生产实现。

## 1. 测试目标

| 编号 | 目标 |

| TEST-GOAL-002 | 验证来源缺失、重复原始编码、批次整体校验、资料不足、验收不通过、非法入库等异常路径。 |

## 2. 测试范围

### 2.1 纳入范围

1. 回收批次来源信息校验；
2. 电池包登记和系统追溯编码生成；
3. 原始编码疑似重复处理；
4. 批次提交验收整体校验；
5. 验收通过、待补充资料、不通过；
6. 已验收待入库电池入库；
7. 库存查询和追溯时间线；
8. 权限拒绝、审计日志和删除保护。

### 2.2 排除范围

1. 企业间流转、出库、接收确认；
2. 综合利用；
3. 真实监管平台报送；
4. 正式数据库、API、性能压测和自动化测试脚本；
5. 真实二维码硬件和真实检测设备。
