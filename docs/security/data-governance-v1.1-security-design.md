## 2. 权限编码

| 权限编码 | 用途 |
| --- | --- |
| `dq:rule:read` | 规则读取。 |
| `dq:rule:toggle` | 企业规则启停。 |
| `dq:check:execute` | 发起质量检查。 |
| `dq:check:read` | 查看检查任务和结果。 |
| `dq:issue:read` | 查看质量问题。 |
| `dq:issue:assign` | 分配质量问题。 |

## 3. 企业隔离

- 所有查询由登录上下文注入 `enterprise_id`。
- 禁止客户端提交 `enterprise_id`。
- 跨企业 ID 访问返回 403。
- 跨企业拒绝必须写审计，审计原因使用 `CROSS_ENTERPRISE_ACCESS_DENIED`。
- DQ-001 全系统唯一检查不得泄露其他企业电池明细。

## 4. 幂等安全

所有写接口强制 `Idempotency-Key`：

- 同键同请求返回首次结果。
- 同键不同请求返回 409。
- 成功写入和幂等成功状态同事务提交。
- 业务失败回滚主事务，再独立记录失败幂等和拒绝审计。

## 5. 审计安全

审计范围：

- 规则启停。
- 检查任务创建、完成、失败。
- 问题生成、分配、开始处理、提交处理、复核、关闭、退回。
- 无权限、跨企业、非法状态、缺少原因或证据、幂等冲突。

审计字段要求：

- 企业。
- 操作人。
- 对象类型和对象 ID。
- 动作。
- 变更前状态。
- 变更后状态。
- 操作结果。
- 操作原因或拒绝原因。
- 请求 ID 或幂等键摘要。

## 6. 规则保护

V1.1 不提供以下能力：

- 在线修改规则 SQL 或脚本。
- 在线修改参与字段。
- 在线修改规则判断条件。
- 上传自定义检查脚本。
- 用户自定义规则表达式。

系统管理员只能查看规则定义和按企业启停规则。

## 7. 当前结论

安全设计待评审。评审通过前不得开放生产实现。
