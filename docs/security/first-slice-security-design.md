# 第一切片安全设计 V0.1

文档名称：第一切片安全设计  
系统名称：面向动力电池回收利用企业的流转协同与追溯管理系统  
当前阶段：system-design  
当前检查点：设计评审  
文档状态：待评审  
输入基线：C4 第一切片需求与原型基线 V1.0

## 1. 安全目标

第一切片安全设计目标是保证回收批次、电池档案、验收、入库、库存和追溯数据只能由授权用户访问和操作；越权、失败操作和删除保护必须留下审计；企业数据必须隔离；敏感信息不得泄露到日志和响应中。

## 2. 认证设计

| 项 | 设计 |
| --- | --- |
| 登录方式 | 用户名和密码登录。 |
| 会话凭证 | JWT。 |
| Token 携带方式 | `Authorization: Bearer <jwt>`。 |
| Token 内容 | 用户 ID、企业 ID、角色编码、权限编码、过期时间和签发时间。 |
| Token 过期 | 课程实现阶段可设置 2 小时；生产环境按安全策略调整。 |
| 登录审计 | 成功和失败均写入 `audit_log`。 |

## 3. 密码存储

- 密码不得明文存储。
- 后端使用 BCrypt 或同等级哈希算法保存 `password_hash`。
- 登录失败不得提示用户是否存在，只返回统一失败消息。
- 日志中不得输出密码、密码摘要或 JWT。

## 6. URL 和方法级权限

后续实现应同时启用：

- URL 层拦截：未登录不能访问业务接口。
- 方法级权限：服务方法使用权限编码检查。
- 数据范围校验：所有业务查询和更新必须限制 `enterprise_id`。
- 状态校验：权限通过后仍必须执行业务状态校验。

## 7. 企业数据隔离

- JWT 中携带用户所属 `enterprise_id`。
- 业务表查询必须附加 `enterprise_id` 条件。
- 写入业务表时 `enterprise_id` 来自登录上下文，不接受前端直接指定。
- 跨企业读取、修改、入库或追溯默认拒绝，并写入审计日志。
- Repository 更新必须同时带业务主键和 `enterprise_id` 条件，避免只按主键更新跨企业数据。

## 8. 审计设计

| 审计场景 | 动作编码 | 结果 |
| --- | --- | --- |
| 登录成功 | `AUTH_LOGIN_SUCCESS` | `SUCCESS` |
| 登录失败 | `AUTH_LOGIN_FAILED` | `FAILED` |
| 越权操作 | `FORBIDDEN_OPERATION` | `FORBIDDEN` |
| 入库失败 | `INBOUND_FAILED` | `FAILED` |
| 删除已生效记录被拒绝 | `DELETE_EFFECTIVE_RECORD_DENIED` | `FORBIDDEN` |
| 权限配置变更 | `PERMISSION_CHANGED` | `SUCCESS` |

审计记录字段至少包含操作人、企业、动作、对象类型、对象 ID、结果、拒绝原因、操作时间、IP、User-Agent 和 traceId。

## 9. 附件安全

- 首期附件选填。
- 允许类型建议限制为 PDF、JPG、PNG、DOCX、XLSX。
- 单个附件大小建议不超过 20 MB。
- 文件名需做规范化处理，存储路径不得直接使用用户输入。
- 附件下载必须校验登录、权限和企业数据范围。
- `POST /attachments` 只创建 `TEMP` 临时附件，不要求业务对象 ID。
- 创建批次或补充资料绑定附件时，必须校验附件属于当前企业、当前上传用户、状态为 `TEMP`、未过期且未被其他对象绑定。
- 禁止绑定其他企业附件、其他用户临时附件或已过期临时附件；拒绝结果写入 `audit_log`。
- 绑定成功后更新 `business_attachment.binding_status=BOUND`、`object_type` 和 `object_id`。
- 附件元数据写入 `business_attachment`，过期 `TEMP` 附件由定时清理任务处理。

## 10. 参数校验

- Controller 层使用 Bean Validation 做必填、长度、格式校验。
- Service 层执行业务规则校验，包括状态、企业范围、仓库库位启用状态和归属关系。
- `warehouseCode` 格式：`WH-{3位数字}`。
- `locationCode` 格式：`{仓库编码}-A{2位数字}-R{2位数字}-L{2位数字}`。
- 所有校验失败使用统一响应结构和错误码。

## 11. SQL 注入和 XSS 防护

- 使用 MyBatis-Plus 参数绑定，不拼接用户输入到 SQL。
- 排序字段使用白名单。
- 文本字段输出到页面时由前端框架默认转义。
- 富文本不在第一切片范围内。
- 响应头建议启用基础安全头，包括 `X-Content-Type-Options` 和 `X-Frame-Options`。

## 12. 敏感配置

| 配置 | 处理方式 |
| --- | --- |
| 数据库密码 | 环境变量或外部配置文件，不提交仓库。 |
| JWT 密钥 | 环境变量，不写入源码。 |
| 附件目录 | 环境变量配置。 |
| 日志目录 | 环境变量配置。 |

`.gitignore` 应排除本地配置、密钥、日志和上传附件目录。
