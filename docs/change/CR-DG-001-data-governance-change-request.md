# CR-DG-001 数据治理能力变更请求

文档状态：待评审
提出日期：2026-09-22
目标基线：V1.1
当前处理决定：待评审

## 1. 变更原因

当前系统已经具备业务追溯、审计、编码和数据字典基础。为进一步提升课程项目的软件工程完整性和业务数据可信度，拟在第一业务切片基础上增加轻量级数据治理能力，支持数据标准、数据质量检查和质量问题闭环。

## 2. 变更目标

在动力电池回收流转系统中增加轻量级数据治理能力，使系统能够围绕已产生的回收、登记、验收、入库和库存数据执行质量检查，发现问题，分配责任人，跟踪处理和复核结果，并在看板中展示质量状态。

## 3. 变更范围

- 数据标准。
- 数据质量规则。
- 质量检查任务。
- 质量问题。
- 问题处理与复核。
- 数据质量看板。

## 4. 排除范围

- 数据湖。
- 大数据平台。
- 复杂元数据平台。
- 自动血缘解析。
- AI 自动修复。
- 区块链。
- 真实监管平台。
- 自定义脚本规则引擎。

## 5. 影响分析

| 影响项 | 初步影响 |
| --- | --- |
| 业务需求 | 需要新增数据治理需求编号 `UR-DG`、`FR-DG`、`NFR-DG`、`AC-DG`，不覆盖原 `UR-C4`、`FR-C4`、`AC-C4`。 |
| 用户角色 | 复用现有角色，业务主管承担质量问题处理与复核，系统管理员管理质量规则，管理人员查看看板。 |
| 数据库 | 预计新增数据质量规则、检查任务、质量问题、整改记录等表；V1.1 技术设计前不冻结表结构。 |
| API | 预计新增数据质量规则、检查任务、质量问题处理和看板接口；V1.1 技术设计前不冻结接口。 |
| 页面 | 预计新增规则列表、发起检查、检查结果、问题列表、问题详情、分配责任人、处理复核和质量看板。 |
| 权限 | 需要新增或扩展数据质量查看、检查执行、问题处理、复核和规则管理权限。 |
| 测试 | 需要新增 `TC-DG`，覆盖质量规则、检查任务、问题状态、处理复核、权限和看板。 |
| 部署 | 预计不引入新的基础设施；若后续设计定时清理或定时检查，需要补充调度配置。 |
| 项目工期 | 会推迟正式实现分支创建，需要先完成 V1.1 需求、原型和技术设计评审。 |

## 6. 处理决定

待评审。

当前仅提出变更请求并进入分析，不批准需求、不冻结数据库和 API、不初始化正式工程、不编写生产业务代码。
