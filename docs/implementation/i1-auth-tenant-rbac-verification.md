## 本轮整改范围

- 统一登录、当前用户、用户列表、角色、权限和审计接口 DTO Envelope。
- 将幂等请求摘要改为规范化请求内容的 SHA-256 摘要。
- 新增 V4 Flyway 迁移，将 `idempotency_record.idempotency_key` 扩展到 128 字符。
- 将幂等失败记录和拒绝审计改为独立事务持久化。
- 新增 V5 Flyway 迁移，纠正 V1.0/V1.1 内置角色权限矩阵。
- 增加内置角色最大权限边界：禁止业务角色获得权限管理、通用审计和越界业务权限，禁止系统管理员获得业务执行权限。
- 拆分成功审计与拒绝审计事务边界：成功审计随业务事务提交或回滚，拒绝审计独立事务持久化。
- 补充 `@Valid` 和 `Idempotency-Key` 长度校验。
- 将 ID 生成切换为 MyBatis-Plus Snowflake 生成器。
- 清理生产配置默认数据库账号，开发默认值移入 `application-dev.yml`。
- 修复前端 Token 存在但用户缓存缺失时的认证恢复逻辑。
- 移除生产构建中的演示账号密码预填。
