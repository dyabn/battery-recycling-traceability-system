## 3. 用户流程

### 3.1 正常入库闭环

1. 登录为回收操作员；
2. 创建回收批次，填写来源类型、来源主体名称和交接日期；
3. 登记电池包，系统生成系统追溯编码；
4. 提交批次验收；
5. 登记验收结果为通过；
6. 切换为仓库管理员；
7. 在待入库列表选择电池；
8. 选择启用仓库 WH-001 和启用库位 WH-001-A01-R01-L01；
9. 确认入库；
10. 在库存列表查询电池；
11. 查看电池追溯详情。

### 3.2 关键异常路径

| 场景 | 原型验证点 |
| --- | --- |
| 重复原始编码 | 输入 ORI-DUP-001 时，系统提示疑似重复并要求人工核实。 |
| 批次提交失败 | 来源必填信息缺失或批次为空时，提交验收被拒绝。 |
| 待补充资料 | 验收结果为待补充资料时，必须填写说明；补充后可回到待验收。 |
| 验收不通过 | 必须填写不通过原因，不允许进入入库。 |
| 无效仓库或库位 | 选择停用仓库或停用库位时，入库失败并记录审计。 |
| 越权操作 | 无入库权限用户尝试入库时被拒绝并记录审计。 |
| 已生效记录禁止删除 | 对已生效批次、验收或入库记录执行删除时被拒绝。 |

## 5. 原型评审脚本

| 步骤 | 评审动作 | 预期观察 |
| --- | --- | --- |
| REVIEW-C4-001 | 以回收操作员进入，创建包含完整来源信息的批次。 | 能看到必填字段和选填字段；关联单据号不是必填。 |
| REVIEW-C4-002 | 登记新电池包。 | 系统生成追溯编码；电池体系可选择“未知”。 |
| REVIEW-C4-003 | 输入重复原始编码 ORI-DUP-001。 | 系统提示疑似重复，禁止直接有效建档。 |
| REVIEW-C4-004 | 提交空批次或来源缺失批次。 | 系统拒绝提交，状态保持不变。 |
| REVIEW-C4-005 | 对待验收电池登记“通过”。 | 电池进入已验收待入库。 |
| REVIEW-C4-006 | 对待验收电池登记“待补充资料”。 | 必须填写补充资料说明，补充后可重新提交。 |
| REVIEW-C4-007 | 对待验收电池登记“不通过”。 | 必须填写不通过原因，不能入库。 |
| REVIEW-C4-008 | 以仓库管理员办理入库。 | 必须选择启用仓库和启用库位，成功后库存可见。 |
| REVIEW-C4-009 | 使用无权限角色尝试入库。 | 操作被拒绝，出现审计日志。 |
| REVIEW-C4-010 | 尝试删除已生效记录。 | 删除被拒绝，提示后续更正或撤销流程。 |
| REVIEW-C4-011 | 查看追溯详情。 | 关键业务状态变化进入生命周期事件，安全事件进入审计日志。 |
