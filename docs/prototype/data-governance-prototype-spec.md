# 数据治理低保真原型规格 V0.1

文档状态：待评审
关联变更：CR-DG-001
目标基线：V1.1

## 1. 原型定位

本原型用于验证数据治理需求，不是正式前端代码。原型只覆盖轻量级数据治理闭环，不改变第一业务切片 V1.0 原型和技术设计基线。

## 2. 页面清单

| 编号 | 页面 | 目标 |
| --- | --- | --- |
| UI-DG-001 | 数据质量规则列表 | 查看固定规则、维度、适用对象和启用状态。 |
| UI-DG-002 | 发起质量检查 | 选择检查范围并启动手工检查。 |
| UI-DG-003 | 检查结果 | 查看检查任务状态、结果摘要和发现的问题。 |
| UI-DG-004 | 质量问题列表 | 按状态、责任人、规则筛选问题。 |
| UI-DG-005 | 问题详情 | 查看问题对象、规则、描述、状态和审计。 |
| UI-DG-006 | 分配责任人 | 由业务主管分配处理人。 |
| UI-DG-007 | 处理与重新检查 | 责任人提交处理，业务主管重新检查。 |
| UI-DG-008 | 数据质量看板 | 查看检查次数、问题数量、关闭率和未关闭问题。 |

## 3. 主要用户流程

```text
业务主管进入数据质量
-> 查看规则
-> 发起检查
-> 查看检查结果
-> 分配质量问题
-> 责任人处理
-> 业务主管重新检查
-> 关闭问题
-> 看板更新
```

## 4. 原型验证场景

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| REVIEW-DG-001 | 查看质量规则 | 可以看到固定候选规则，规则不支持自定义脚本。 |
| REVIEW-DG-002 | 发起质量检查 | 检查任务生成，状态从 `RUNNING` 到 `COMPLETED`。 |
| REVIEW-DG-003 | 发现质量问题 | 检查结果生成问题列表。 |
| REVIEW-DG-004 | 分配责任人 | 问题状态变为 `ASSIGNED`。 |
| REVIEW-DG-005 | 提交处理 | 问题状态变为 `SUBMITTED`。 |
| REVIEW-DG-006 | 重新检查通过 | 问题状态变为 `CLOSED`。 |
| REVIEW-DG-007 | 重新检查失败 | 问题状态变为 `REJECTED`。 |
| REVIEW-DG-008 | 查看看板 | 看板指标随检查和问题状态变化。 |

## 5. 原型位置

静态低保真原型位于：

```text
prototype/data-governance/
```

可直接打开 `index.html` 查看，不需要后端、数据库或正式前端工程。

原型规格为 V0.1 待评审稿。完成实际操作评审前，不得关闭数据治理需求阶段。
